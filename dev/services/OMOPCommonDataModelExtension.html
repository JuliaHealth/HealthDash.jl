OMOPCommonDataModel ​

HealthDash.OMOPCommonDataModelExtension Module
julia
OMOPCommonDataModelExtension

An explorer for the OMOP Common Data Model, backed by OMOPCommonDataModel.jl.

Every CDM table is a struct in that package, so we reflect over them and let you pick a table from a dropdown to see its struct name, CDM table name, and every field with its type. Selecting a table updates the view instantly - the whole schema is rendered up front and shown/hidden with Vue, so there's no page reload and no network call.

source
HealthDash.OMOPCommonDataModelExtension.cdm_tables Method
julia
cdm_tables() -> Vector{DataType}

Return every OMOP CDM table type defined by OMOPCommonDataModel, sorted by table name.

Each CDM table (person, drug_exposure, ...) is a struct that subtypes OMOPCommonDataModel.CDMType. This walks every binding in that package and keeps the concrete structs that subtype CDMType - nothing about the schema is hard-coded here, so it always matches the installed package version.

Example

julia
using OMOPCommonDataModel

tables = cdm_tables()
length(tables)          # => number of CDM tables (e.g. 39)
first(tables)           # => OMOPCommonDataModel.AttributeDefinition

HealthDash.OMOPCommonDataModelExtension.field_items Method
julia
field_items(T::DataType) -> String

Build the HTML <li> list of a table's columns. Each field of the struct is a CDM column, and its Julia type is the column type. A Union{..., Missing} field is a nullable column, so it is unwrapped with nonmissingtype and tagged as optional.

source
HealthDash.OMOPCommonDataModelExtension.omop_ui Method
julia
omop_ui() -> Stipple.ParsedHTMLString

Build the OMOP CDM Explorer shown on the dashboard: a dropdown of every table from cdm_tables plus one hidden detail panel per table. Picking a table reveals its panel client-side with Vue (v-model + v-show), so there is no page reload.

source
HealthDash.OMOPCommonDataModelExtension.table_details Method
julia
table_details(T::DataType) -> String

Render the detail panel for one CDM table: its qualified struct name, the CDM table name from table_name, the struct ... <: CDMType line, and the column list from field_items.

source
HealthDash.OMOPCommonDataModelExtension.table_name Method
julia
table_name(T::DataType) -> String

Convert a CDM struct type to its OMOP table name, e.g. ConceptAncestor -> "concept_ancestor". Handles the camelCase boundaries, including runs of capitals (CDMSource -> "cdm_source").

Example

julia
table_name(OMOPCommonDataModel.DrugExposure)   # => "drug_exposure"
